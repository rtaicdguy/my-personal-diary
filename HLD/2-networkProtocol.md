There are 2 type of networking protocol architecture
* Client Server
  * Example are HTTPs and Web Sockets
  * They are based on centralised systems (Servers)
* P2P Architecture
  * Every participant acts as both server and client
  * Peers share resources directly with each other
  * Example is blockchain

Transport Layer:
* TCP (Transmission Control Protocol) Connection: 
  * Ordering maintained between packets of data
  * Slow
  * Error checking and reliable
* UDP (User Datagram Protocol)
  * Unordered
  * Fast
  * No error checking and unreliable
  * Eg are Video Steaming/ Videocall etc
